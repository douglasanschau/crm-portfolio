# Capturas de tela

Esta pasta está reservada para imagens de demonstração do LeadFup.

## Sugestões de capturas
- `login.png` — tela de autenticação.
- `sales-pipeline.png` — funil de vendas com etapas e registros fictícios.
- `business-details.png` — visualização de um negócio com dados demonstrativos.
- `activities.png` — lista ou painel de atividades.

## Checklist antes de publicar
- Utilize exclusivamente dados fictícios.
- Remova nomes, e-mails, telefones, documentos e informações de clientes reais.
- Oculte tokens, URLs internas, identificadores sensíveis e informações de infraestrutura.
- Verifique notificações, abas do navegador e outros elementos que possam revelar dados pessoais.
- Confira a imagem em tamanho real antes de adicioná-la ao repositório.

Não foram adicionadas imagens nesta primeira versão porque ainda não foram fornecidas capturas revisadas da aplicação.
